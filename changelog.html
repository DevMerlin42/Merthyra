Build 63July 30, 2026

App Store release preparation and Apple Vision Pro

Build 63 consolidates the current Merthyra product into the release project intended for App Store submission.

  • Added a native visionOS destination and spacious window configuration.
  • Completed platform gating for iPhone-only and iPad-only capabilities.
  • Prepared automatic signing and widget extension packaging for distribution.
  • Removed the experimental Journal feature and its entitlement from the release.
  • Kept the unified Writer, workspace suite, Apple integrations, widgets, Live Activities, and file-backed persistence.
  • Validated all Swift files through iOS, macOS, and visionOS parse paths.
Build 58July 29, 2026

Writer Pro

The unified Writer expanded from a focused note editor into a professional writing environment.

  • Editor, Preview, Split, and Combined live-rendered layouts.
  • Stable tabs, dual documents, Zen Mode, Typewriter Mode, and session restore.
  • Writing aids, readability, grade level, dialogue, density, sentence, and vocabulary insights.
  • Wiki links, backlinks, link suggestions, broken-link detection, media, OCR, and handwriting.
  • Version history, writing sessions, goals, document types, and long-form organization.
  • Markdown, PDF, DOCX, HTML, ePub, RTF, and plain-text export paths.
Builds 51–57July 27, 2026

The new unified Writer

Merthyra merged the old Writer and Wiki into one file-backed system without replacing existing user content.

  • Idempotent legacy document migration using stable source IDs.
  • Sections, persistent disclosure state, nested tags, syntax coloring, and inline editing.
  • Correct tag commitment only after trailing whitespace.
  • Workspace-scoped Writer Trash, restore, permanent deletion, and conflict tombstones.
  • Responsive iPhone library and editor flows.
  • Cursor and scroll preservation while typing long documents on iPhone.
Builds 45–50July 26, 2026

The Liquid Glass workspace redesign

The old dark-and-gold interface gave way to the cleaner Merthyra product language used today.

  • New Light, Dark, Dracula, Graphite, Aurora, and custom theme architecture.
  • Liquid Glass cards, controls, sidebars, headers, sheets, and dashboard panels.
  • Workspace-scoped Home, Projects, Tasks, Calendar, Files, People, Analytics, Automations, and Integrations.
  • Creator Flow production boards and connected account analytics.
  • Modern spreadsheets with formulas and CSV workflows.
  • Safer OAuth routing, workspace switching, and file-backed persistence.
WebsiteJuly 2, 2026

The original Merthyra website and docs launched

The first website introduced the early dark-and-gold writing workspace, public beta access, documentation, changelog, privacy policy, beta terms, and GitHub-powered forums. The current redesign keeps those working foundations while matching the app Merthyra became.
