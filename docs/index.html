GETTING STARTED

Merthyra Docs

Merthyra is a workspace for writing, planning, whiteboards, spreadsheets, calendars, reminders, and shared work. Personal workspace data is mirrored into a Merthyra folder in iCloud Drive.

Writer

The Writer Library groups Notes, Docs, and Notebooks into one place. Writer text is mirrored as Markdown so it remains readable outside Merthyra.

Notebooks

Notebook pages export to PDF for portability. Merthyra also retains its editable drawing source alongside the PDF so Apple Pencil strokes can continue to be erased, moved, or extended inside Merthyra.

Workspace packages

An .mws package is Merthyra's portable workspace archive. Opening one in Merthyra imports the included workspace data. An .mdb file carries a Dashboard layout that can be imported independently.

Accounts

An account is optional for personal use. Sign in with Apple enables People, invitations, and shared workspaces. Account deletion is available from the profile panel in the app.
